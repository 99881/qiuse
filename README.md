# 湘赣金秋 · 三代四人自驾路书

> 一份真正能带上路的家庭自驾出行包：**手机网页 + A4 打印件 + 每晚自动推送**。

2026 年 11 月，一家四口（两位老人 + 一位 7 岁孩子 + 司机）、9 天 8 晚、约 2250 公里：
深圳 → 永州零陵 → 桐子坳银杏 → 衡阳县西渡（接人/办事）→ 韶山 → 井冈山茨坪 → 黄洋界 → 信丰脐橙园 → 深圳。

在线看：**https://99881.github.io/qiuse/**

---

## 它解决了什么

带老人孩子长途自驾，真正麻烦的不是开车，是这些：

| 痛点 | 这里的做法 |
|---|---|
| 纸质路书在车上翻不方便 | 一套手机网页，单文件 HTML，**没网也能看**（图片全部内嵌） |
| 老人看不清小字 | 每份打印件都是 A4 大字、带勾选框，比例 100% 就能打 |
| 每天不知道明天该准备什么 | **每晚 20:30 自动推送**到飞书：明天怎么走、要带什么、今晚做什么 |
| 天气一变，全篇数据要重算 | 行程数据只存一份 `scripts/trip.json`，网页与推送共用 |
| 景点预约时间容易记错 | 单独一页写清三个入馆时段、检证规则、当天时间表 |
| 预算、药箱、衣物散落各处 | 按人拆成单页清单：奶奶 / 爸爸 / 小朋友 / 全家行李 |

## 三个设计取舍

**1. 手机优先，但不是一个 App**

所有页面都是纯静态 HTML，单个文件自带样式和图片，微信/短信把链接发过去就能看。
`text.html` 是纯文字版（109 KB），专门给弱网和老人手机准备的——比 PDF 在手机上缩放强太多。

**2. 打印件必须真的能打**

A4、单栏、8—9pt 正文、4—5 mm 勾选框、不依赖彩色。
打印预览里选「实际大小 / 100%」，勾选框才是 4 mm；选"适应页面"会缩成 2 mm，笔都下不去。

**3. 数据只有一份**

九天行程写在 `scripts/trip.json`：日期、地点、经纬度、当天时间表、要带的东西、今晚要准备的事。
网页靠它、推送也靠它。改一个地方，两边同时更新，不会出现"PDF 说 08:00、网页说 06:30"这种事故。

## 每晚 20:30 的自动推送

用 GitHub Actions 定时跑，**电脑关机也照发**，通过飞书自建应用发到私聊：

```
【明天 D5 11/18】
韶山三馆：09:00 生平展区 · 11:00 专题展区 · 12:00 故居
住：韶山（连住）
天气：7—16℃，降雨 10%，0.0 mm

明天怎么走：
  07:00 早饭
  08:50 到纪念馆检证口
  09:00 生平展区
  11:00 专题展区
  11:40 吃碗面
  12:00 故居（内景）
  13:40 回酒店

明天要带下车：
  · 四个人的身份证原件
  · 预约凭证截图
  ...

今晚要准备：
1. 四个人的身份证放在一起，别分开放
2. 把三通票预约截图存相册
  ...

注意：每个馆单独检证、逾时作废；故居 12:00 段最紧，11:55 到门口
```

实现只有三个文件：

- `scripts/trip.json` —— 行程数据
- `scripts/daily_push.py` —— 拼消息（含实时天气，Open-Meteo 免费接口）
- `.github/workflows/daily.yml` —— 每天 UTC 12:30（北京 20:30）触发

## 想改成自己的？

1. **Fork 或下载**
2. **改 `scripts/trip.json`**：日期、地名、经纬度、时间表、清单——这是唯一的数据源
3. **改页面文字**：`index.html` 和各页的标题/线路，替换成自己的行程
4. **换打印件**：用 Chrome 打开改好的 HTML → 打印 → 另存为 PDF（A4、边距 0、勾选背景图形）
5. **接推送**（可选）：
   - 飞书开放平台建自建应用 → 开 `im:message:send_as_bot` → 拿到 App ID / Secret
   - 把 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_OPEN_ID` 存进仓库 Secrets
   - Actions 里手动 Run 一次验证
6. **开 GitHub Pages**：Settings → Pages → 选 `main` / `(root)`

## 技术栈

纯静态，没有框架、没有构建步骤：

- HTML + CSS（手写，移动优先）
- Leaflet（`vendor/` 里自带，离线可用）
- Chrome headless 打印 A4 PDF
- GitHub Pages 托管
- GitHub Actions 定时任务
- 飞书开放平台 `im/v1/messages`
- Open-Meteo 免费天气 API

## 关于这个仓库

这是**一趟真实家庭行程**的公开镜像，用来分享做法，也是给自己留档。

- **不含**姓名、手机号、身份证、订单号；

- 行程中的天气数据来自 Open-Meteo，会变，出行前请自行刷新。

代码部分欢迎参考、改造、自用；图片请不要商用。如果这套东西帮你少踩一个坑，那就值了。
